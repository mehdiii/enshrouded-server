# Rejoindre le serveur Enshrouded « Nesspa Enshrouded »

## Infos du serveur

| | |
|---|---|
| **Nom** | `Nesspa Enshrouded` |
| **Adresse** | `51.75.204.124:15637` |
| **Mot de passe** | tape `/connexion` sur Discord pour le recevoir en privé |
| **Joueurs max** | 4 |
| **Difficulté** | Default |

## Méthode 1 : depuis le jeu (recommandée)

1. Lance **Enshrouded** sur Steam.
2. Sur l'écran d'accueil, clique sur **Jouer**.
3. Choisis ton personnage, ou crée-en un. Les personnages sont sauvegardés sur ton PC et peuvent passer d'un monde à l'autre.
4. Clique sur **Rejoindre**.
5. Dans la barre de recherche, tape `Nesspa`.
6. Sélectionne **Nesspa Enshrouded**, puis clique sur **Rejoindre**.
7. Entre le mot de passe (commande `/connexion` du bot Discord) et valide.

## Méthode 2 : par les favoris Steam (si le serveur n'apparaît pas dans la liste)

1. Dans Steam, ouvre le menu **Affichage → Serveurs de jeux**.
2. Va dans l'onglet **Favoris** et clique sur **+** (*Ajouter un serveur*).
3. Entre `51.75.204.124:15637`, puis clique sur **OK**.
4. Le serveur apparaît dans tes favoris. Clique sur **Se connecter** : Enshrouded se lance et rejoint le serveur.
5. Entre le mot de passe quand il est demandé.

## Problèmes fréquents

- **Le serveur n'apparaît pas dans la liste** : vérifie que le filtre de recherche est vide et que tu as tapé le nom sans faute. Sinon, utilise la méthode 2.
- **« Version mismatch » ou version incompatible** : mets à jour Enshrouded dans Steam (clic droit sur le jeu → *Propriétés* → *Mises à jour*). Le serveur se met à jour automatiquement.
- **Mot de passe refusé** : il est sensible aux majuscules et minuscules. Copie-colle-le plutôt que de le retaper.
- **Serveur plein** : le serveur accepte 4 joueurs, dont une place réservée à l'admin. Il peut donc être plein à 3 joueurs « Amis ».
- **Rien ne marche** : préviens l'admin. Le serveur est peut-être en train de redémarrer pour une mise à jour (ça prend quelques minutes).
